# A/B 联调 B00：离线适配记录

本次工作包输入为 A 原始 JSON 或 ZIP，以及调用方明确提供的组织 ID、项目 ID、资料是否为演示；输出原始快照、原始字节 SHA-256、适配器及合同版本、B 合同包、内容哈希和警告。代码为 `backend/integrations/a/offline.py` 和 `mapping.py`；验收为样例稳定转换、合同引用、人员与时间保真，以及 ZIP 路径、数量、大小和附件哈希检查。此阶段不写数据库、不调用 A、不确认在线资格或授权。

使用时先调用 `read_export(path)`，保留返回的原始字节；再调用 `convert(raw, snapshot, org_id=..., project_id=..., is_demo=...)`。ZIP 中 `task.json` 与所列附件必须存在且哈希、长度匹配；JSON 单独输入不能证明附件可用。测试样例的项目 ID 取样例本身，仅用于离线转换，不构成服务授权。转换只支持 inspection；未知场景拒绝。事件缺乏可靠发生时间时为 null，原事件保留在 payload；原始快照保留问题历史、手填人员和旧报告时间，不能将日期级时间用于精确耗时。

当前限制：转换结果尚未接入 B 接收接口、持久化、队列或在线附件连接器；原始字节需要调用方持久化。合同的历史接收链目前只接受演示来源；本适配器不绕过此限制。A 的实际资格、撤回、身份和服务凭据未验证。后续 B01—B07 仍待实现与验收，真实联调依赖 A 服务和私有配置。
