# B07｜培训题库、学习包与学习记录

状态：待开发。依赖：B03审核、B04已发布知识；B06仅用于复盘转培训。

## 给AI的执行指令

执行B07。先读[公共设计](../01-平台设计与公共执行约束.md)和B03/B04实际审核发布服务。实现单选、多选、案例问答及学习包、作答、反馈。不搭建完整LMS、直播课堂、复杂学习路径或证书体系。

题目来源必须是有授权且已审核的知识版本。模型生成题目只进入候选；客观题按规则评分，开放题按明确要点评分并标为建议结果。复用现成表单组件和审核机制。

## 页面

| 路由 | 内容 |
|---|---|
| `/training/questions` | 候选/审核/发布题目，场景、类型、来源筛选 |
| `/training/questions/{id}` | 题面、标准答案、评分要点、来源（教员权限） |
| `/training/packages` | 学习包、固定版本、题目顺序 |
| `/learn` | 学员可访问学习包 |
| `/learn/attempts/{id}` | 保存作答、提交、结果与解释 |
| `/training/results` | 教员按权限查看完成情况和错误类型 |

## 表

| 表 | 字段/约束 |
|---|---|
| training_questions | type、scene_code、current_revision、scope |
| question_revisions | question_id、version、stem、options、answer、rubric、source_versions、state |
| learning_packages | title、package_key、version、role_scope、state；key+version唯一 |
| learning_package_items | package_version_id、question_revision_id、position |
| training_attempts | learner_id、package_version_id、state、started/submitted_at、result_state |
| training_answers | attempt_id、question_revision_id、answer、score、feedback、score_kind、row_version；组合唯一 |

分数和反馈保存评分规则及模型版本，人工复核保留修改原因。不要只存一项可变总分而丢失各题依据。

## 接口

前缀`/api/v1`：
`POST /training/questions/generate`、`GET /training/questions`、
`PATCH /training/questions/{id}/draft`、`POST /training/questions/{id}/submit-review`、
`POST /training/packages`、`POST /training/packages/{id}/publish`、
`POST /training/attempts`、`PUT /training/attempts/{id}/answers/{question_id}`、
`POST /training/attempts/{id}/submit`、`GET /training/attempts/{id}/result`。
补充教员复核评分接口并记录审计。学员获取题面使用专用响应Schema，不复用带答案的管理端Schema。

## 实现细节

- 无可信整改结论的案例只生成识别/补证据类题，不编造标准处置。
- 图片识患只使用可确认的现场照片，文字截图不混入。
- 发布学习包固定题目版本；修改题目产生新版本，不改变历史成绩。
- 保存作答幂等；提交后锁定本次作答，重复提交返回同结果。
- 模型评分失败保留作答并显示待评分，不能填0分冒充完成。
- 撤回来源使相关题目停止新使用；历史成绩保留，正文显示受当前授权限制。

## 验收标准

- [ ] 学员接口和页面源数据中都不含提前泄露的答案/评分要点。
- [ ] 题目来源、版本、审核者和评分依据可追溯。
- [ ] 刷新后已保存作答存在；重复提交不重复计分。
- [ ] 题目修改不改变既有学习记录。
- [ ] 学员不能访问其他学员记录；教员仅在权限范围查看。
- [ ] 模型建议评分和人工确认评分分开显示。
- [ ] 来源撤回后停止开新练习，历史成绩不泄露受限正文。
- [ ] 无模型时不伪造题目质量或反馈评测结果。
