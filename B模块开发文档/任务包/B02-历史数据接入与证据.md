## 页面

| 路由 | 内容 |
|---|---|
| `/sources` | 来源类型、映射模板、最后同步与状态 |
| `/imports/new` | 选来源、预览字段映射、异常提示、提交 |
| `/imports/{id}` | 新增/更新/跳过/失败计数和错误记录 |
| `/records` | 项目、日期、记录类型、来源、质量状态筛选 |
| `/records/{id}` | 原文、生效值、来源定位、图片及其关系可信度 |

## 表

| 表 | 字段/约束 |
|---|---|
| data_sources | kind、namespace、config、mapping_version、cursor；敏感连接信息仅引用配置 |
| import_batches | source_id、input_hash、status、counts、rule_version |
| source_documents | source_id、external_report_id、sha256、title、asset_id；保留来源身份 |
| source_records | source_id、external_record_id、document_id、record_kind、current_version；来源+外部ID唯一 |
| source_record_versions | record_id、version、content_hash、raw_fields、effective_fields、provenance、batch_id |
| evidence_items | document_id、record_version_id、locator、type、asset_id、relation_confidence |
| record_links | from_record、to_record、relation_type、method、review_state |

source_record_versions同记录同内容不重复产生；跨来源重复通过record_links处理。稳定ID缺失时明确后备策略，不能只用可变描述生成身份。

## 接口

前缀`/api/v1`：
`POST/GET /sources`、`POST /imports/preview`、`POST /imports`、`GET /imports/{id}`、
`GET /records`、`GET /records/{id}`、`GET /evidence/{id}`、`POST /record-links/{id}/confirm`。
预览不创建正式业务记录；导入返回202和job_id。数据源选择受控文件引用，不接受任意服务器路径。

## 实现步骤

1. CSV接入：保留原39字段，按record_kind区分detail/review/summary；images解析为列表并记录坏值。
2. 复用治理工作台导出或只读查询实现接入；读不到数据库时使用可验证导出，不擅自修库。
3. Excel接入保存字段映射和实际来源标识；图片使用已有行锚点逻辑，无法明确对应则保留候选。
4. Pandera等校验日期、枚举、字段类型、缺失；输出异常集合，不一遇空值就丢整批。
5. 通过内容哈希增量生成版本；批次失败可重试，显示实质处理计数。
6. 展示来源证据；缺附件可保留记录并标记不可用，不能伪造预览。
7. 核对机场表与治理工作台重合，先给候选关系，再经确认合并统计口径。
