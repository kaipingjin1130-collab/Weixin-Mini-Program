## 页面

| 路由 | 内容和行为 |
|---|---|
| `/workbench` | 当前用户待办、最近任务与失败项；尚无业务数据时真实空状态 |
| `/jobs` | 类型/状态筛选、分页、详情、错误摘要、允许时重试 |
| `/settings/access` | 管理员查看/设置B内角色范围，不改变A项目事实权限 |

## 表

| 表 | 字段与约束 |
|---|---|
| user_links | id、issuer、subject_id、display_name；issuer+subject_id唯一 |
| role_bindings | user_id、role、scope_type、scope_id；组合唯一 |
| audit_events | actor、object_type/id、action、object_version、request_id、timestamp；日志不存令牌 |
| processing_runs | kind、object_id、idempotency_key、input_hash、queue_job_id、progress、result_ref、error |
| file_assets | storage_key、sha256、mime_type、size、org/project范围、来源、availability |

队列表由Procrastinate等组件管理。processing_runs只记录业务状态，不重新实现队列锁。内容哈希可用于物理去重，但不同来源的授权关系不能被合并丢失。

## 接口

前缀`/api/v1`：
`GET /me`、`GET /jobs`、`GET /jobs/{id}`、`POST /jobs/{id}/retry`、
`GET /assets/{id}/content`、`GET /audit-events`。
补足管理员角色绑定列表/变更接口，纳入OpenAPI及审计。

## 实现步骤

1. 核对运行环境和可复用UI，锁定实际使用版本；缺环境时说明，不部署未经授权的外部服务。
2. 建立配置读取、错误结构、request_id、健康检查；不把密钥写入仓库。
3. 做统一身份适配器及`authorize(actor, action, resource)`能力。mock身份仅限明确开发模式，正式模式启动时拒绝mock。
4. 提供数据库迁移及开发库初始化说明；不连接旧治理库执行迁移。
5. 验证Procrastinate入队、重试、worker中断恢复及事务边界。若验证不通过，报告证据和替代方案，不自行另造队列。
6. 实现文件存储适配器：文件ID到受控路径，拒绝目录穿越；记录读取时也做范围授权。
7. 使用无业务副作用的样例任务验证状态和幂等，页面显示真实数据。

## 验收标准

- [x] API和前端可启动；依赖、配置、命令有说明。
- [x] 学员直接调用管理员接口被拒绝；不同项目访问被拒绝。
- [x] mock配置不会在正式模式静默使用。
- [x] 同幂等键同内容返回已有任务；异内容409。

- [x] 业务写入与入队失败能恢复，无“有任务但无对象”永久悬挂。
- [x] 文件路径不能由请求任意指定；越权和撤权后访问拒绝。
- [x] 日志没有令牌或完整敏感报告正文（本轮演示任务范围与代码检查）。
- [x] 页面加载、空、失败及重试状态可操作，不是静态假数据。
