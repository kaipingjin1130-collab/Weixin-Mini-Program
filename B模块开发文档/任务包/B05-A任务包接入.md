## 实现步骤

1. 入站先验证服务身份和项目范围，再校验Schema及内容限制。
2. 按合同规范化计算哈希，事务保存接收结果和幂等身份。
3. 排队处理，返回202；重试返回原receipt，不能重复创建。
4. 按受控access_ref下载附件，限制类型/大小，校验sha256，保存来源权限。
5. 建立事件与证据关联。无时间留空；未知事件保留原文并提示兼容限制。
6. 未完成全部附件时明确缺失与可用性，涉及缺附件结论不能算证据完整。
7. 撤回立即写入可用性状态，触发下游失效处理接口。B06/B07尚未实现时保留待处理事件，不能声称已完成下游撤回。

## 验收标准

以下验收限定模拟包、mock服务身份与受控本地连接器；真实服务验签和网络附件协议未验收。[本地验证记录](../../b-risk-knowledge/reports/B05-validation.md)。

- [x] 同键同内容不新增包；同键异内容409。
- [x] 同任务版本异内容409；新版本更新当前指针；旧版晚到不覆盖。
- [x] 身份/项目不匹配拒绝，不能凭正文org_id取得权限。
- [x] 时间缺失、附件失败、未知事件有明确结果，不补造事实。
- [x] 哈希不匹配附件不标为可用；任意URL或路径不能触发读取。
- [x] worker重试不生成重复事件和附件关系。
- [x] 模拟A合同用例全部执行；真实A未连接明确记录。
- [x] 撤回重复调用幂等，在线访问立即失效。
