# B08｜场景配置与扩展验证

状态：待开发。依赖：B03及B04/B06/B07中至少一个实际消费者。

## 给AI的执行指令

执行B08。先读[公共设计](../01-平台设计与公共执行约束.md)和已经存在的场景文件/模板。把版本化配置接入管理与激活流程，不重新设计前面模块，不开发通用低代码工作流。

配置支持术语、分类、扩展字段、检查模板、复盘规则参数、出题模板。配置中不允许任意代码执行。新的业务行为超出配置表达能力时明确需要开发，不谎称无需代码即可扩展任何场景。

## 页面

| 路由 | 内容 |
|---|---|
| `/settings/scenes` | 场景码、版本、状态、消费者 |
| `/settings/scenes/{id}` | 字段Schema、字典、模板、校验预览、激活 |

## 表

`scene_packs`：code、version、schema、vocabulary、templates、rule_parameters、state、created_by、activated_at；code+version唯一。激活仅影响后续对象，旧对象继续指向旧版本。

## 接口

前缀`/api/v1`：
`GET /scene-packs`、`POST /scene-packs/validate`、`POST /scene-packs`、
`POST /scene-packs/{id}/activate`。
场景配置查看与修改分别授权。校验接口不激活、不更改旧对象。

## 实现步骤

1. 盘点前面任务的硬编码场景，提取真正可配置的部分。
2. 用JSON Schema验证配置及扩展字段；有合适UI时使用JSON Forms，否则复用现有表单组件。
3. 消费者按scene_code+version加载，模板缺失返回明确错误。
4. 增加第二场景，例如消防检查/机电巡查；业务内容标记需审核，不能虚构法规要求。
5. 复用检索或培训完成一条实际演示，记录必要代码改动，不能假称零改动。

## 验收标准

- [ ] 第二场景复用同一发布、检索或培训流程。
- [ ] 不合法Schema、非法规则参数、重复版本不能激活。
- [ ] 切换场景版本不改变旧卡片、复盘和题目的解释。
- [ ] 没有任意代码执行入口或静默修改全库字段。
- [ ] 缺字段/未知场景有可理解错误，不回退为无关场景答案。
- [ ] 说明本次扩展需要多少配置与代码变更，以实际证据展示扩展性。
