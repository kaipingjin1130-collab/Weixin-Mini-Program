## 1. 如何把这些文档交给AI

在能读取本项目文件的AI开发会话中，复制下面的指令。第一轮只执行B00，不要一次性要求实现全部功能。

```text
请阅读本项目“B模块开发文档/README.md”和“B模块开发文档/任务包/B00-接口合同与领域模型.md”，执行B00。
严格按任务文件中的“给AI的执行指令”工作。本轮只做接口合同、数据模型、样例及合同验证，不实现业务平台。
读取平台设计和A/B接口草案，检查已有项目状态后开始。能独立完成的工作直接推进。
与A尚未确认的设计标记为proposed，列出待确认事项，但不要因此停止本地Schema、样例和验证工作。
不要改动原始报告、已有数据治理工作台或其他旧系统；不要安装、部署或上传额外系统。
完成后报告文件位置、实际验证结果、未确认事项，并更新总索引中B00的状态；未完成验收不得标为已通过。
```

后续使用：

```text
请执行“B模块开发文档/任务包/BXX-对应文件名.md”中的完整指令。
先读总索引和该任务依赖的实际交付物，检查它们是否满足启动条件，再实现本任务。
复用已有代码和已验证能力，不重复建设前置模块。仅完成本任务，不提前扩展后续任务。
提交真实页面、接口、迁移、必要测试与运行说明；明确模拟验证和真实联调的区别。
```

如果AI无法读取本地文件，把该任务文件和它要求的公共设计/接口文件一并发送。只发送任务标题不够。调用外部模型时不得未经授权上传真实报告、身份资料或业务数据。

## 4. 三道项目验收线

### 第一条：历史数据到知识
- [ ] 真实数据增量导入，保留原文、生效值、来源及质量状态。
- [ ] 人工只处理异常与候选审核，无需重复填写已有字段。
- [ ] 知识审核发布后可检索，答案引用能打开证据。
- [ ] 来源数、记录数、独立事件数、知识数分别统计。

### 第二条：任务到复盘培训
- [ ] 完整任务包接收，真实时间线可查看，缺失信息明确标记。
- [ ] 复盘结论可追溯，审核后转经验和培训题。
- [ ] 学员作答、评分、反馈和历史版本可核对。
- [ ] 演示任务包清楚标记模拟，真实联调单独记录。

### 第三条：扩展与可靠性
- [ ] 增加第二个场景，复用既有检索或培训流程。
- [ ] 切换模型适配器并重跑固定评测；必要时重建向量集合。
- [ ] 重复导入、并发编辑、worker中断、附件失败可正确处理。
- [ ] 权限撤销或来源撤回后，下游内容停止新增使用。

## 6. 每次任务完成如何交接

开发AI更新对应任务文件末尾“执行记录”，只写当前有效结果：状态、交付路径、验证命令/结果、限制、下一步。总索引同步状态，不重复维护第二份进度计划。已有用户手工修改须先核对，不能用旧模板覆盖。

“已完成”至少意味着该任务要求的代码、检查和说明齐全；A未联调时只能标“本地验收通过，待A联调”。文档或模型自评不能替代实测。
