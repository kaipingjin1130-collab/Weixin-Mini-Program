# 巡查工作台与报告中心整理（2026-10-29）

基线：codex/ab-fusion-integration，d691151（已保留并发更新的登录错误提示与多管理员支持）。本次仅整理 A 网页端导航和页面，不部署线上。

## 页面行为

- 侧栏单一“巡查工作台”入口，包含新建巡查、分派任务、待办提醒、统一列表、搜索、状态筛选及分页。
- 原“一键上报”表单、签名与草稿接口保留；任务详情、现场材料接收与后续办理接口保留。
- 通过 sourceReportId / records.sourceReportId 明确关联报告与任务。关联报告显示为任务的“原始报告”，不重复列为一次巡查；草稿始终保留编辑入口。文档版本仍在报告中心独立保留。
- 待整改和待复核指标为按主状态归类的任务数，不是问题条数。项目范围沿用现有授权及筛选。
- 分派任务按钮仅对当前项目管理员或负责人显示，最终写入权限继续由原服务端判断。
- 侧栏单一“报告中心”入口，内部“巡查报告 / 成果归档 / 历史资料 / 成果接入”页签。历史资料和成果接入继续挂载既有 B 页面，不更改 B 服务。
- 原表单、归档及 B 深层链接继续可用；旧任务列表链接进入统一工作台，带任务 ID 的链接仍打开相应任务。

## 数据与登录

没有数据库迁移，没有删除、转换历史记录，没有修改登录、认证桥接、接口或小程序源码。联动列表只读组合服务端授权数据。
